How it connects

How each integration helps

Each tool helps answer a practical question: did the customer pay, did the store deliver, and what should you check next?

PayPal Sandbox

Explore a recorded payment
How it helps
Checks the PayPal payment behind a test order, so a checkout message alone can’t be mistaken for money received. The test workspace also confirms payments and checks payment notifications before trusting them.
Where it’s available
The private test workspace needs PayPal Sandbox access. Here, you can explore the saved payment from an earlier test checkout.
Good to know
Test money only. The public site never starts a checkout or contacts PayPal.

Investigation assistant · DeepSeek on Modal

Read an earlier investigation
How it helps
Helps trace a missed delivery by checking payment and ticket records, explaining what it found and suggesting where to look next.
Where it’s available
The assistant runs in the private workspace. Here, you can read a saved investigation from a separate earlier order.
Good to know
The answer stays tied to payment and delivery records. Reading the saved investigation makes no new AI request.

AG Studio

Optional workspace tool
How it helps
Follow an order through linked payment and ticket records, and ask questions about saved cases.
Where it’s available
A private workspace with the required AG Studio licence.
Good to know
Available separately from this recorded example.

Bryntum Scheduler (Community)

Optional workspace tool
How it helps
Compare when orders were paid and delivered, and spot tickets that missed their promised time.
Where it’s available
The private workspace, after this optional view is set up.
Good to know
This optional delivery view is separate from the timeline in the recorded example.

KERNEL

Optional checkout recording
How it helps
Records an approved test checkout in a remote browser, so you can review what the customer experienced alongside payment and delivery.
Where it’s available
The private workspace, when its owner enables a test session.
Good to know
Available separately from this recorded example. The public site starts no remote session.

Postman

Optional workspace tool
How it helps
Runs repeatable checks on CrashCart’s payment and delivery records and the files it downloads.
Where it’s available
A separately set up private workspace.
Good to know
These checks are separate from the recorded example. Downloading its files makes no payment or AI request.

Shopify and WooCommerce

Preview
How it helps
Store order and delivery connections are in preview. They haven’t been tested with a real store yet.
Where it’s available
Not available to connect your store yet.
Good to know
This example uses a workshop test store. Store installation and connection are not available yet.

Before you start

What you can use today

  • Test payments onlyThe example follows a $29 workshop ticket due within 60 seconds. Test payments use PayPal Sandbox funds.
  • Connect your storeShopify and WooCommerce connections are still a preview. Store installation, customer accounts and store billing aren’t available yet.
  • Private workspace accessThe private workspace needs setup and access from its owner. No sign-in is needed for this recorded example.
  • A recorded exampleExplore saved records here. A new payment or AI investigation needs the private test workspace.

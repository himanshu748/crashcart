In the private test workspace

Follow the payment. Find the missing delivery.

Private test workspace These steps describe CrashCart’s private test workspace. This public example doesn’t start a checkout or run the assistant.

  1. 01

    Start a test checkout

    Start a checkout in PayPal’s test environment and approve it yourself. No real card is charged.

  2. 02

    Confirm the approved payment

    Approve the checkout on PayPal, then choose to confirm it in CrashCart. CrashCart checks PayPal before completing the test payment.

  3. 03

    See whether delivery was on time

    Compare the confirmed payment with the store’s ticket record. The promise stays the same: one ticket, within 60 seconds.

  4. 04

    Find the missing step

    Ask the assistant to follow the payment and delivery records. It points to what happened and what to check next. You can stop it from taking further steps.

    About these recordings
    Good to know
    
            
    Does this demo contact PayPal or run AI?
    No. It reads saved records. No payment, AI request or store connection is started here.
    
            
    Why are there two cases?
    The 8 November case shows a real Sandbox payment and its saved AI investigation. The 22 October case compares the original store with the repaired rule using the same saved payment. They are separate orders.
    
            
    Who decides whether delivery was on time?
    The assistant chooses which records to inspect. Fixed code checks payment, ticket count and the unchanged 60-second promise. The assistant cannot override that result.
    
            
    Can I connect my store?
    Not on this public demo. Shopify and WooCommerce connectors are in preview and have not been verified with a real merchant store.
    
            
    Can I run a new Sandbox checkout?
    The separate private workspace can use your own PayPal Sandbox and AI access. Read the setup guide.
    
            
    What can I download?
    The 22 October recorded input, both outcomes and a keyless offline replay. Downloading a file does not run it.

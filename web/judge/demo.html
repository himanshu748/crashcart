    Questions
    
      
    Good to know
    
      
    
        
    
          Does this page take a payment or contact PayPal?
          
    No. It only reads saved records that ship with the page. It doesn’t start a checkout, contact PayPal, connect to a store or ask the AI anything.
    
        
    
        
    
          What exactly was recorded?
          
    One earlier PayPal Sandbox test checkout against the owned workshop test store, which sells a $29 ticket promised within 60 seconds of payment. The original store lost the delivery. The “recovered order” runs the same saved payment through the repaired store. It’s a replay, not a new payment or a live store.
    
        
    
        
    
          Is the AI assistant running here?
          
    No. When this copy includes a saved investigation that passes its checks, you can read it as saved text. Otherwise that section stays hidden. Either way the result comes from the payment and ticket records, not from the assistant.
    
        
    
        
    
          Which stores does CrashCart work with today?
          
    One owned workshop test store. Shopify and WooCommerce readers exist as a separate preview, but they haven’t been connected to a real store yet, so there’s no install or connect flow today.
    
        
    
        
    
          How would I check my own orders?
          
    CrashCart runs in a private workspace. You sign in with an access key from your workspace owner, and test checkouts need PayPal Sandbox details. This recorded page doesn’t sign you in or create anything.
    
        
    
        
    
          What can I download?
          
    The records for both orders and the saved checkout input, as JSON you can read but which don’t run anything. There’s also a replay test (ZIP) that reruns the failure on your computer with no payment.
